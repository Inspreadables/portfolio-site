Design Principes

De Baak Design System

Zes kernprincipes die alle visuele communicatie vormgeven

1. Ruimte

  • Genereuze witruimte (min 60px padding)
  • Content ademt en krijgt aandacht
  • Reflecteert "ruimte om te ontdekken"
  • Consistente vertical rhythm

2. Rust

  • Geen agressieve kleuren
  • Subtiele animaties (300-600ms)
  • Zachte schaduwen
  • Gedempte saturatie

3. Natuurlijk

  • Organische vormen (6-8px radius)
  • Aardse kleurentinten
  • Natuurfotografie
  • Texturen van papier/hout

4. Toegankelijk

  • WCAG AA compliant contrast
  • Duidelijke visuele hiërarchie
  • Touch-friendly (min 44px)
  • Leesbare fontgroottes (16px+)

5. Professioneel maar Warm

  • Autoriteit zonder corporate feel
  • Benaderbaar zonder casualiteit
  • Persoonlijke toon ("jou", "je")
  • Mensgerichte beelden

6. Erfgoed ontmoet Modern

  • "sinds 1947" positionering
  • Klassieke typografie
  • Moderne layout
  • Tijdloos, niet trendy

Kostenanalyse

Claude.ai abonnement vs API-gebruik voor verschillende scenario's

Gebruik Scenario Volume/Maand Claude.ai API Kosten Aanbeveling
Sporadisch gebruik 1-10 prompts €0* ~€0.50 ✅ Claude.ai
Regulier gebruik 10-50 prompts €0* ~€5 ✅ Claude.ai
Intensief gebruik 100 prompts €0* ~€22 ✅ Claude.ai
Automatisering 1000+ prompts N.v.t. ~€220 🔧 API
Enterprise volume 10.000+ prompts N.v.t. ~€2.200 🔧 API + Batch

* Inbegrepen in bestaand abonnement (Pro: €18-20/maand, Max: €200/maand)

💡 Belangrijkste Inzicht

Voor typisch gebruik bij De Baak (1-50 prompts per maand voor het maken van trainingsmaterialen) is een Claude.ai abonnement de meest kosteneffectieve oplossing. De prompts kosten niets extra bovenop je bestaande abonnement.

API-gebruik wordt pas interessant bij geautomatiseerde workflows (1000+ prompts/maand) of systeem-integraties.
