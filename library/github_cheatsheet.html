De Gouden Regel

Sluit geen Claude-chat voordat je het script hebt uitgevoerd. Twee plakken, één ENTER, klaar. Daarna mag de chat weg.

01

Een HTML-pagina opslaan

Kopieer de HTML-code uit Claude

Open Git Bash:
cd ~/inspreadables

Voer het script uit:
./save-session.sh <project> <naam>

Plak HTML in output.html → sla op

Druk op ENTER → 🚀 klaar

02

Een chat & prompt opslaan

Vóór het sluiten — kopieer prompt én outputcode

Voer script uit:
./save-session.sh de-baak-lms pagina-hero-nl

Plak prompt in prompt.md
Plak code in output.html

Sla op → druk ENTER

✅ Verwijder de Claude-chat
